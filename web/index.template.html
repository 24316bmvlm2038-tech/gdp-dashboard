Everything here runs inside your tab. A published page like this one is sandboxed and cannot make network requests: nothing you type leaves the browser, and nothing can be fetched into it. Every answer above comes from the weights embedded in this file.

Search lives in the full app, where there is a real network. It has two modes, and the app always states which one you are in:

  • With Claude — Claude runs the search itself and cites what it used.
  • With Clode-mini — the app searches (DuckDuckGo by default; Brave or Serper with a key) and shows the sources. Clode-mini has a 6,658 word vocabulary and a 128 token context, so it cannot read a web page and does not write those answers.

What it knows

Trained on a generated corpus of chat exchanges — 80 countries with their capitals, languages and currencies, chemical elements, arithmetic, unit facts, Python how-tos, definitions and its own persona, from a 3.1M token corpus with a 6,658 word vocabulary. It answers 94% of a held-out question set correctly — every category except arithmetic is perfect. Outside that corpus it invents things confidently: it is roughly 0.004% the size of a frontier model, and it cannot search the web.

How it works here

The weights ship int8-quantised and are dequantised on load. Each token is one pass over a KV cache, so replies stream at reading speed on a laptop CPU. Nothing is sent anywhere — turn off your network and it still answers.

How it was made

Tokenizer, transformer, the hand-derived backward pass, AdamW and the training loop are all written from scratch in NumPy; every gradient is checked against finite differences in tests/test_model.py. It was trained in stages on a growing corpus, each stage warm-started from the last — the curve above is the first stage, taking it from random initialisation to a working model.
